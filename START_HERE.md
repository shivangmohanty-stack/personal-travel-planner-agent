# Start here

Open **[INSTRUCTIONS.md](INSTRUCTIONS.md)** for the complete guide:

1. Download and open the project.
2. Install the packages and configure your own Gemini API key.
3. Create your local app login.
4. Start the server and use the itinerary planner.
5. Understand the code and upload your demo video.

If you already completed setup, double-click `start.cmd`, keep its terminal open,
and visit **http://127.0.0.1:8001**. Sign in using your existing app account.
